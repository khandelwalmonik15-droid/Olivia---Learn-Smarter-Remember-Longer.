# 🐱 Olivia — Learn Smarter. Remember Longer.

**Olivia** is a browser-based study companion developed by **Team Oggy** to help students save, organize, and revise useful information while browsing the web.

Built as a student project for **Kalvium Utsav-e-Diwali**, Olivia aims to make online learning more convenient by bringing study tools closer to the browser.

## ✨ Features

- 📌 **Save Web Content:** Save useful webpage content or selected text for later reference.
- 📝 **Notes:** Keep saved study material organized in one place.
- 🃏 **Flashcards:** Create flashcards to support revision and active recall.
- 🧠 **Quiz Generation:** Generate practice questions to test your understanding.
- 💾 **Local Persistence:** Keep supported saved study material available after reloading the extension.

*Note: Features may evolve as development continues.*

## 🎯 Our Goal

Students often find helpful information across multiple websites, but turning that information into notes and revision material can take time.

Olivia aims to simplify this workflow so students can spend more time learning and less time organizing.

## 🚀 Getting Started

To try Olivia locally:

1. Download or clone this repository.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the downloaded Olivia project folder containing `manifest.json`.
6. Open the extension from Chrome's toolbar and explore its available features.
